# Dataset provenance

This repository includes a 30-image benchmark sample under
`datasets/bossbase_runs/sample_30/`. The package supplied for this repository
describes the sample as derived from **BOSSbase 1.01**. The original BOSSbase
archive is not included.

- Official source: [Binghamton University Digital Data Embedding download page](https://dde.binghamton.edu/download/)
- Source archive and checksum recorded in [the supplied manifest](datasets/BOSSbase_1.01_manifest.json)
- The sample's PNG and JPEG carriers, stego images, and evaluation outputs are
  included as project evidence, not as an original image collection.

The package's MIT declaration in `pyproject.toml` describes the toolkit code.
It does **not** assert that third-party BOSSbase imagery is MIT licensed. The
official download page names the dataset but does not state a redistribution
license in the page text. Consult the dataset owners before reusing or
redistributing the images outside this research sample.
